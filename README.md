# HelloPurr
HelloPurr es una pequeña aplicación interactiva desarrollada en MIT App Inventor como parte de mis primeras prácticas de desarrollo de aplicaciones móviles.

El proyecto parte de una interacción sencilla con un gato, pero decidí agregarle una pequeña capa adicional de funcionalidad mediante una pantalla de acceso y navegación entre pantallas.

## 💡 ¿Qué hace?

La aplicación comienza con una pantalla que solicita una contraseña. Al presionar **Submit**, el programa utiliza una estructura condicional para comprobar si la contraseña ingresada es correcta.

Si coincide, permite acceder a una segunda pantalla. Si no coincide, el campo se limpia para permitir un nuevo intento.

En la segunda pantalla aparece un gato acompañado del mensaje **“Pet the Cat!”**. Al presionar la imagen, la aplicación reproduce un sonido de maullido, creando una interacción sencilla entre el usuario y la aplicación.

## 🧠 Conceptos aplicados

Este proyecto me permitió practicar algunos fundamentos de programación y desarrollo en MIT App Inventor:

- Programación basada en bloques
- Eventos mediante `Button.Click`
- Condicionales `if / else`
- Comparación de valores
- Uso de `PasswordTextBox`
- Navegación entre pantallas
- Manejo de imágenes y archivos de audio
- Uso del componente `Sound`

## 🛠️ Tecnologías

- MIT App Inventor
- Programación visual por bloques
- Componentes multimedia
- Diseño básico de interfaces móviles

## 🌱 Lo que aprendí

Aunque es una aplicación sencilla, HelloPurr me ayudó a comprender cómo diferentes componentes de una interfaz pueden conectarse con la lógica de programación.

Fue una introducción práctica al uso de eventos y condiciones, además de mostrarme cómo una aplicación puede reaccionar a las acciones del usuario, cambiar entre pantallas y utilizar recursos multimedia.
